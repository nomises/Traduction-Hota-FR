===== Map name =====
Tutorial

===== Map description =====
Si vous n'avez jamais joué à aucun jeu de stratégie au tour par tour de la série Heroes of Might and Magic, commencez par ce scénario. Vous pourrez ainsi vous familiariser avec les bases du jeu, notamment les commandes et l'interface.

Le territoire maudit de l'autre côté est très dangereux. Les gardes insistent : vous devez d'abord régler les problèmes dans le sud-est, puis seulement ensuite avancer.

Les gardes se réjouissent d'apprendre que vous avez vaincu le héros au sud-est. Ils acceptent de vous laisser passer, mais vous avertissent que les terres de l'autre côté sont semées d'embûches.
